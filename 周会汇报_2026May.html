检测机制 — 它是怎么判断"做对了"的

🔍 检测类型（不止一种）

类型判断逻辑示例步骤
手部中心入区手 bbox 中心点落在 ROI 多边形内① 拉取工装
框重叠手/工具 bbox 与 ROI 区域 IoU > 0⑩ 取泡棉
组合检测双手同时覆盖两个 ROI + 持续 0.75s③ 压紧下盖
工具检测压线笔/扫码枪 bbox 进入指定 ROI⑦ 压线 / ⑨ 扫码
标签检测基座+下盖同时被 YOLO 检出且中心重叠② 下盖安装
连续帧判定连续 N 帧满足条件才触发（防抖动）④ 绕圈 5 帧

⚙️ 关键技术细节

  • 滞回滤波：手部 ENTER 阈值 0.6 / EXIT 阈值 0.4 + IoU 跨帧匹配，防止检测框闪烁导致误判
  • 基座绑定：部分 ROI 坐标跟随基座位置动态调整（bound_region_ids），工装移动后检测区跟着走
  • 越序/跳步检测：SOP 步骤链有严格顺序，手进入非当前步骤区域时记录事件日志
  • 循环逻辑：步骤⑩-⑬ 需要拿取→安装→再拿取→再安装，通过 loop_count 计数器管理
  • 帧计数器：每个步骤有独立计数器（如排线 6 帧、扫码 3+3 帧、风扇 5 帧），防止误触发

业务逻辑 & 大模型问答设计

❌ 业务痛点（四条）

  1. 人力成本高：传统"师带徒"需大量专职讲师与助教，无法弹性伸缩
  2. 培训周期长：新人从入职到独立上岗周期长，期间不产生业务价值，隐性产能浪费
  3. 质量难统一：人工教学受限于讲师经验与状态，SOP 标准动作难以精准传递
  4. 考核主观：人工监考评分标准不一致，跨批次学员考核结果不可比

✅ 方案路线

  1. AI-Camera 实时捕捉 → 替代人眼盯岗
  2. 时空动作检测 + SOP 逐帧比对 → 替代人工判断
  3. 7×24 无人化陪练 → 去掉讲师时间约束
  4. 机器自动评分 → 消除人为偏差
  5. 大模型问答兜底 → 减少一对一答疑人力

会议投稿 · CAIBDA 2026

VCP: 单阶段小样本目标检测

VCP: Single-Stage Cosine Classifier and Prototype Learning for Few-Shot Object Detection
Xiang Fei, Mengru Li, Jinming Huang*, Jacob Liu, Xiaofu Zhang, Xiaojiao Xu  |  曲阜师范大学 + GoerTek + Free-Optics + 慧米智能

🔍 研究动机

  • FSOD 方法 100% 基于 Faster R-CNN（FSCE/DeFRCN/TFA 等），利用 RPN 做前景过滤
  • 但工业部署的主力是 YOLO 单阶段检测器——"发表的方法不能部署，部署的系统缺乏研究"
  • 单阶段 FSOD 的核心难点：没有 RPN，dense prediction 产生大量低质量 proposal，分类器面临极端正负样本不平衡
  • 首次在 TFA 标准协议下系统研究 YOLO11s 的 FSOD 表现

🛠️ VCP 方法

  1. Cosine Classifier：替换 YOLO11s 线性分类头为余弦相似度分类 sc = cos(f, pc)/τ，f 和 pc 均 L2 归一化
  2. Visual Prototype：从 support set 的 GT bbox 提取 RoIAlign 特征 → 均值 → L2 归一化 → 写入分类器权重
  3. Semantic Prototype (Fused)：Florence-2 对目标 crop 生成 <DETAILED_CAPTION> → BART 文本编码 → 可学习投影 Wf → 与视觉原型加权融合：pc = α·pc_vis + (1-α)·Wf·pc_text，α=0.7
  4. 关键：Florence-2 仅在训练时提取语义原型，推理时原型已固化在权重中，零 VLM 推理开销

💡 核心发现 — Recall Booster：余弦分类器的梯度 ∂cos/∂f = pc − cos·f，迫使特征向原型方向对齐。24 组 P-R 分解实验显示：余弦分类器系统性推高 Recall、拉低 Precision。这在 VOC 上净收益为正（Recall 提升空间大），COCO 上净收益为负（基线 Recall 已高，Precision 损失超过 Recall 收益）。

🔬 P-R Tradeoff 假说

24 组 P-R 分解实验（VOC×12 + COCO×12，覆盖 1/3/5/10 shot × 3 方法）一致性结论：

↑ R
Recall 系统性↑
↓ P
Precision 系统性↓

净收益 ≈ 基线 Recall 提升空间 × P-R 权衡比
VOC：基线 R 低 → 提升空间大 → 正收益
COCO：基线 R 已高 → P↓ 损害 > R↑ 收益 → 负收益
